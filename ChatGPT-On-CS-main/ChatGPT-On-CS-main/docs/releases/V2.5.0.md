# 迎波智能客服 V2.5.0

V2.5.0 将迎波智能客服升级为更适合长期日常使用的“双工作面”桌面产品：伴随助手负责当前客户与回复操作，主窗口负责多店铺运营、异常处理、知识积累和质量复盘。

## 本版重点

- 全新客户经理视角运营首页，集中展示待回复、超时、失败、平台异常和待审核知识。
- 主导航按真实工作任务重新组织：回复审核、店铺与平台、知识库、回复规则和效果分析。
- 伴随助手支持左侧吸附、右侧吸附和自由悬浮，控制入口直接可见。
- 自动识别千牛、微信和企业微信前台窗口，并按平台记忆吸附方向。
- 修复自由悬浮时平台识别停止、窗口探测偶发超时的问题。
- 回复工作台强化会话队列、上下文和回复处理三栏结构。
- 知识候选可从真实对话持续沉淀，并支持审核、查看、编辑、导入、导出和版本治理。
- 增加回复采用率、人工编辑率、失败反馈和七日趋势。
- 完善多平台、多店铺和客服实例的归属与运行状态展示。

## 下载与运行

下载 `yingbo-smart-customer-service_v2.5.0_windows_x64_portable.zip`，完整解压后运行其中的 `迎波智能客服.exe`。

新版会沿用原有配置和本地数据。替换前仍建议通过程序内的数据治理功能导出一次知识库备份。
