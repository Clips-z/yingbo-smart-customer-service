# 迎波智能客服 V2.5.1

V2.5.1 是基于 V2.5.0 的实战体验修正版，重点处理店铺与客户上下文错配、平台切换滞后、待回复重复累计和本地测试程序版本漂移。

## 本版重点

- 确认全部后续功能迭代均建立在 V2.5.0 Git 标签之后，并统一应用版本号。
- 千牛标签位置变化后立即更新店铺，不再等待容易失败的白字 OCR。
- 客户身份未稳定前清空当前回复，不再回退显示其他客户的最近草稿。
- 支持识别新版微信 `WeChatAppEx` 进程，自动跟随当前前台平台。
- 修正京麦、拼多多、抖音写入待回复时使用旧数据库字段的问题。
- 后端服务掉线后切换到明确的重连页面，恢复后重新刷新工作台数据。
- 左右吸附窗口使用 Windows 可见边框零缝贴合，并记忆用户拖动后的宽度；自由悬浮时可调整宽高。
- 千牛切换仍由快速 Windows OCR 发现，但生成回复前改用常驻 RapidOCR 校正客户问题，并修正常见的数字客户 ID 误识别。
- 伴随助手把“最近真实对话”和“一问一答历史”合并为当前客户最近对话，明确显示客户 ID，最多保留 5 条并自动去重、过滤乱码。
- “读取复制内容并生成回复”不再占用界面；真实消息流优先校准 OCR，剪贴板中新复制的客户问题只在 OCR 没有可用原文时静默兜底。
- 当前客户最后一条有效问题与 AI 草稿强制一一对应；不匹配的旧草稿立即隐藏且禁止填入。
- 同一会话出现 OCR 漏帧时保留已经确认的最新问题，不再倒退生成“昨天”等旧消息回复。
- 过滤“智能质检指派给、转交给”等千牛系统提示，避免系统文字进入 AI 问题。
- 采集状态在正常扫描期间保持“采集就绪”，不再反复闪烁“连接中”。
- 左侧聚合接待改为“全部 / 待人工回复 / 已回复”，并标识待人工发送、人工已回复、自动已回复。
- 每个店铺、账号和客户先取最新状态再分类，客户回复后旧待回复记录不会重新出现。
- 保留 V2.5.0 的左侧聚合接待、伴随助手、知识库查看/编辑/导出和质量闭环能力。

## 测试说明

本版本已完成本地运行包验证，发布前覆盖以下实机项目：

1. 千牛四个店铺之间切换时，伴随助手的店铺名立即同步。
2. 千牛客户 ID 与当前聊天窗口一致，切换客户后旧回复消失。
3. 点击回答内容可填入当前客户输入框，不出现 `[object Object]`。
4. 点击待回复客户不会卡死；无法可靠定位时会明确提示并允许继续操作。
5. 点击 `×` 后该客户从待回复消失，不反复重新累计。
6. 客服人工回复后，记录从待回复转入已回复。
7. 切换到微信时，伴随助手显示联系人或群名，并显示对应问答。
8. 京麦、拼多多和抖音产生的有效建议能够进入聚合接待。

## 发布状态

正式发布。Windows 10/11 x64 用户下载完整安装包后即可安装运行，程序内置 Python 3.11、RapidOCR 与 RAG 运行依赖。
