# 迎波千牛 PC 小程序桥接

这是可直接导入淘宝开发者工具的最小桥接工程。它只使用千牛公开的 `my.qn` API：

- 获取当前客户；
- 监听客户切换；
- 打开已经获得官方安全身份的客户会话；
- 校验当前客户后向输入框填入文字。

它不会调用发送消息接口，也不会读取、保存或上传 AppSecret。

## 真机预览

1. 启动最新版迎波智能客服，确认本机端口 `9999` 未被其他程序占用。
2. 在淘宝开发者工具中选择“淘宝 → 商家应用 → 打开项目”，选择本目录。
3. 绑定你自己的应用 AppKey/体验账号。
4. 点击“预览”，勾选“开启千牛 PC 实时预览”，复制预览 URL。
5. 千牛中打开“系统设置”。
6. 按住 `Ctrl+Shift`，右键单击导航栏空白处，打开“开发者设置”。
7. 粘贴预览 URL 并打开。
8. 伴随助手诊断应显示“官方桥接：已连接 · PC 小程序”。

如果工具禁止访问本机 HTTP 地址，请只在开发/真机预览配置中允许：

`http://127.0.0.1:9999`

不要关闭生产环境的域名校验，也不要填写第三方助手的 AppKey。
