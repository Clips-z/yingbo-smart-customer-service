快速开始

  1. 启动软件并允许本机网络访问。
  2. 打开需要接待的平台客户端并登录。
  3. 确认左侧平台状态为“在线”。
  4. 进入“设置 → AI 配置”，填写模型信息并检查连接。
  5. 选择回复模式后启动工作。

三种回复模式

仅提示

只生成建议，不操作聊天窗口。

辅助回复

点击填入后定位联系人并写入输入框，由人工发送。

无人值守

自动定位并发送，启用前请先完成测试。

配置普通大模型

在“大模型类型”选择 OpenAI 或相应服务商，填写模型名、以 /v1 结尾的 API 地址与 API Key。客服人设和本地知识库会应用于普通模型。

配置 Coze

  1. 先在 Coze 将智能体发布到 API 渠道。
  2. 大模型类型选择“Coze 智能体”。
  3. 填写地区、Personal Access Token 和 Bot ID。
  4. 点击“检查 Coze 连接”。

Coze 模式使用智能体自身的人设、知识库、插件和工作流，不叠加本地提示词。

多平台运行

微信和千牛可以同时开启。软件按平台分别显示任务，只识别已启动且在线的平台；未启动的平台不会采集消息。

关键词与转人工

  • 关键词匹配：优先返回固定话术。
  • 关键词转人工：命中后暂停自动处理。
  • 关键词替换：发送前替换指定表达。

常见问题

  • 模型失败：检查地址、模型名、Key、余额与网络。
  • Coze 拒绝访问：重新创建 Token，并确认已发布到 API。
  • 平台离线：确认客户端已启动登录且版本受支持。
  • 微信定位失败：确认联系人可搜索、微信未锁定。

安全建议

不要公开 API Key 或 Token。退款、价格承诺和售后争议建议设置转人工规则。首次使用无人值守前，请先用“仅提示”和“辅助回复”验证。
