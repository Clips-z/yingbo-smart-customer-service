# v1.5.1 Runtime Repair Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and publish a self-contained v1.5.1 Windows release that preserves yesterday's verified WeChat, Qianniu, and RAG repairs on clean machines.

**Architecture:** Package one pinned Python 3.11 embeddable interpreter and three isolated dependency directories generated at build time. Runtime services launch the bundled interpreter, while each Python entry point prepends its own dependency directory before third-party imports. Packaging checks fail early when any required runtime asset is absent.

**Tech Stack:** Electron 26, TypeScript, Node.js build scripts, Python 3.11, RapidOCR, ONNX Runtime 1.20.1, Jest, electron-builder.
