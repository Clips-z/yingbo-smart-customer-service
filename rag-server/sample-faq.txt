店铺基本信息

店铺名称：迎波智能客服旗舰店
主营产品：智能家居设备、智能穿戴设备、智能配件
营业时间：周一至周日 9:00-22:00
客服在线时间：周一至周日 9:00-23:00

退换货政策

1. 七天无理由退换货：自签收之日起7天内，商品未经使用、不影响二次销售的，支持无理由退换货。
2. 质量问题退换货：自签收之日起15天内，因产品质量问题可申请退换货，运费由我们承担。
3. 退货流程：请在订单页面申请退货 → 客服审核通过 → 寄回商品 → 我们验收后退款。
4. 退款时效：验收通过后1-3个工作日内原路退回。
5. 不支持退换的商品：贴身穿戴设备（已拆封）、定制产品、促销特价商品（页面标注不退换的）。

发货信息

1. 发货时间：下单后24小时内发货（节假日顺延）。
2. 发货快递：默认发中通快递，偏远地区发EMS。
3. 运费政策：满99元包邮，不满99元收运费8元。
4. 新疆、西藏、青海、内蒙古加收10元偏远地区运费。
5. 海外暂不发货，仅支持中国大陆地区。
6. 可以备注指定快递，但不保证一定发指定快递。

支付方式

1. 支持微信支付、支付宝、银行卡支付。
2. 支持花呗分期，3期免手续费。
3. 企业采购支持对公转账，请联系客服获取对公账号。

产品常见问题

智能手表续航多久？
正常使用情况下续航3-5天，开启全天心率监测约2-3天。

智能手表防水吗？
支持IP68级防水，可以洗手、淋雨，但不建议游泳和热水浴。

智能家居设备怎么连接？
下载我们的APP，按说明书操作即可连接WiFi，支持2.4G WiFi，暂不支持5G WiFi。

设备保修期多久？
所有产品自购买之日起享受1年免费保修，智能手表享受2年保修。

可以同时连接多个设备吗？
可以，一个账号最多支持连接20个设备。

会员政策

1. 注册即送50积分，积分可抵扣现金（100积分=1元）。
2. 会员等级：普通会员、银卡会员（累计消费满1000元）、金卡会员（累计消费满5000元）。
3. 银卡会员享95折，金卡会员享9折。
4. 生日月双倍积分，金卡会员生日月享专属优惠券。

发票问题

1. 支持开具电子普通发票和增值税专用发票。
2. 开票请在订单页面备注或联系客服，提供抬头信息。
3. 电子发票一般在订单完成后1-2个工作日内发送到邮箱。
